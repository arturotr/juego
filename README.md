Este juego es una aventura gráfica pixelart. 
El entorno de desarrollo es Godot y se está utilizando un plugin concreto de aventuras gráficas llamado Popopchiu.
El lenguaje es nativo de Godot y se llama GDScript.
El plugin en cuestión facilita el uso de Walkable Areas, Regions...así como la creación de personajes,items,marcadores y diálogos entre personajes.
Para las animaciones y dibujos se está utilizando una herramienta llamada pixellab así como la ayuda de nano banana para el planteamiento de ciertos escenarios.
Para facilitar el trabajo de generación de escenarios, se realiza previamente un boceto esbozando las vistas y se detalla claramente en el prompt. 
Posteriormente se refina la imagen generada para que encaje de manera correcta.
